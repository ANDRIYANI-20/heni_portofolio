# Portfolio Heni Andriyani

Portfolio website modern, bilingual (ID/EN), responsive, dengan animasi
scroll-reveal dan popup modal proyek.

## 🚀 Cara Menjalankan

```bash
yarn install      # install dependency
yarn start        # dev server di http://localhost:3000
yarn build        # build production di /build
```

## 📖 Panduan Edit

Lihat **`PANDUAN.md`** di root folder ini untuk panduan lengkap edit
teks, gambar, warna, dan cara menambah section baru.

## 🛠️ Tech Stack

- React 19 + React Router 7
- Tailwind CSS + shadcn/ui
- Lucide React (icons)
- Sonner (toast notifications)

## 📂 Struktur Singkat

```
src/
├── data/mock.js              ← edit teks & data di sini
├── pages/Portfolio.jsx       ← urutan section
├── components/portfolio/     ← semua komponen section
├── contexts/                 ← context bahasa (ID/EN)
├── hooks/                    ← custom hooks
└── components/ui/            ← shadcn components (jangan diedit)
```

Untuk panduan detail, baca **PANDUAN.md**.
